# 面试复盘助手 · 产品规格（当前生效）

> 维护用「真相源」：描述**现在产品实际做什么、关键规则是什么、明确不做什么**。  
> 战略叙事见根目录 `产品介绍-产品经理视角.md`；怎么跑见 `README.md`；怎么配模型见 `模型配置指南.md`。  
> 改行为时先改本文，再改代码与 `CHANGELOG.md`。

**文档对齐版本：** 2026-11-03（对应仓库约 `1.0.0`）

---

## 1. 定位与边界

| 项 | 说明 |
|----|------|
| **定位** | 真实面试结束后的结构化复盘工作台（非模拟刷题机） |
| **形态** | 本地单进程 Web + API（默认 `http://127.0.0.1:8000/`） |
| **模型** | 用户自备 API Key；提示词与分阶段模型可配置 |
| **数据** | 默认落本机：`data/sessions/`、简历注释历史等；打开历史不重跑模型 |

**非目标（当前不做）：** 企业 ATS/批量筛人；纯题库模拟对练主路径；强制云端账号与社交分享。

---

## 2. 主流程（必须保持的闭环）

```text
上传素材 → 文本澄清 1/3（转写）→ 2/3（澄清问题）→ 3/3（问答对）
       → 逐题分析（可读秒、可暂停）→ 逐题/报告/JD 消费
       →（可选）单题修订多版本 → 历史回看
```

原则：**中间可编辑、长链路可中断、结果可沉淀、单题可迭代。**

---

## 3. 输入规则

| 字段 | 必填 | 规则 |
|------|------|------|
| 面试对话 | 是 | `.docx`（可复制文本）；扫描件需用户另转文本 |
| 面试岗位 | 是 | 写入分析上下文，约束评价与改进方向 |
| 简历 | 否 | 有则做结构化摘要；无简历仍可分析，但改进受限并应提示 |
| 简历注释 | 否 | 补充简历未写清的背景/指标/细节；解析与分析均参考 |
| 岗位 JD | 否 | 纯文本或 `.docx`；有 JD / 无 JD 走不同分析模板 |

**简历注释历史：** 带注释进入复盘后自动入库；新建时可点选回填；可删除历史项。

---

## 4. 文本澄清向导

| 步骤 | 目的 | 用户动作 |
|------|------|----------|
| 1/3 转写 | 确认文稿大致内容 | 可编辑 → 确认 |
| 2/3 澄清问题 | 确认面试官问题及追问背景 | 可编辑 → 确认 |
| 3/3 问答对 | 校验问答匹配（重点看问题） | 可编辑 → 开始分析 |

- 每步确认后进入下一步；未完成向导的会话应能回到对应确认步。  
- 等待态提供**阶段读秒**；阶段切换后秒数重置。

---

## 5. 逐题分析

### 5.1 输出结构（固定四段）

1. 问题考察点  
2. 原文回答  
3. 原回答不妥之处  
4. 合理回答（改进示例；应以简历为骨架，允许合理补全表述维度）

### 5.2 过程规则

| 规则 | 说明 |
|------|------|
| 进度 | SSE/流式进度；**第一题完成后即可进入结果浏览** |
| 暂停 | 不再启动**新题**；进行中的题可跑完；已完成题可浏览 |
| 继续 | 从尚未完成的题接着分析 |
| 跳转 | **暂停中或全部完成后**，支持输入题号跳转 |
| 读秒 | 分析等待态展示读秒，降低卡死感 |

## 6. 结果呈现

| Tab | 用途 |
|-----|------|
| 逐题分析 | 一页一题；版本切换、修订、翻页/跳号 |
| 长篇报告 | 完整 Markdown；可下载；同题多版本按顺序叠加 |
| 岗位 JD | 回看本次 JD；未提供则空态 |

---

## 7. 单题修订与版本

| 规则 | 说明 |
|------|------|
| 何时可改 | 整场分析**已完成**或**已暂停** |
| 依据 | **当前正在查看的版本** + 用户本次修改要求 |
| 版本号 | 追加 V2、V3…；默认展示**最新版** |
| 删除 | 可删任意版本；**至少保留一版**（允许删掉最初版） |
| 报告 | 修订后同步重生成；同题各版本叠加展示 |

---

## 8. 会话与持久化

- 侧边栏：列表展示标题、状态、题量、时间等；支持重命名、删除。  
- 打开历史会话 = **读盘展示**，不重复调用模型。  
- 会话产物目录：`data/sessions/{session_id}/`（该目录默认不入库）。  
- 密钥仅存在本地 `.env`（仓库只保留 `.env.example`）。

## 9. 配置与可维护触点

| 触点 | 路径 | 何时改 |
|------|------|--------|
| 环境变量示例 | `.env.example` | 新增/更名配置项 |
| 模型与业务配置 | `config/llm_config.py` | 分阶段模型、超时等 |
| 提示词 | `prompts/*.txt` | 改分析口径与文案策略 |
| 编排/API | `src/pipeline/`、`src/api/` | 改流程与接口契约 |
| 前端交互 | `web/` | 改页面流程与控件 |

---

## 10. 已知边界（勿当缺陷反复开需求）

- 依赖可复制文本的 PDF/DOCX；无内置 OCR。  
- 输出质量取决于用户所选模型与提示词；产品提供流程与约束，不保证面试结果。  
- 纯前端交互问题不一定进后台日志；后台侧重链路与模型排障。  
- 无多人协作、无账号体系、无云端同步。

**未承诺排期的演进方向：** 录音/ASR、跨场次能力画像、教练协作、云端只读分享等。
